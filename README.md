# HowMaHiCo

A parameterized RMarkdown reporting workflow for **LC-immunopeptidomics** (MHC/HLA
peptide) data analysis. It ingests LC-MS search-engine output from multiple tools
(FragPipe, DIA-NN, PEAKS), normalizes it into a single unified long-format table
(`pep_all`), and renders self-contained, interactive HTML QC reports plus csv/xlsx
result exports.

**Distributed as an R package** (mid-conversion, on the `dev` branch — see
`project-style-guide.md` for the target R-package + Docker + Shiny distribution
pattern). `library(HowMaHiCo)` gives you the full function library and the report
templates; this repo also serves as a worked example of the analysis pattern —
useful as a reference for setting up similar immunopeptidomics QC pipelines.

## What it does

```
LC-MS search output (FragPipe psm.tsv, DIA-NN report.tsv, PEAKS peptide.csv)
      │   read + parse + annotate  (software-specific loaders converge on one schema)
      ▼
pep_all  — unified long-format peptide table
      │
      ▼
inst/rmarkdown/templates/01_mhc_report/skeleton/skeleton.Rmd
      │   rendered via run_howmahico_report() — self-contained interactive HTML
      │   (ID counts, replicate/condition overlaps, size & charge distributions,
      │    RT/ion-mobility/m_z "pseudochromatograms", Area correlation & %CV,
      │    Score/ppm QC, sequence motifs, PTM profile)
      ▼
csv / xlsx result tables  +  optional PNG figure exports
```

Each report is rendered once per analysis subset (e.g. acquisition mode × sample
group), driven by an annotation CSV that maps raw data files to experimental
conditions and replicates.

## Repository layout

| Folder | Contents |
|---|---|
| `R/` | Package source — the ~40 functions (loaders, annotation, counting, plotting, export) plus the `run_howmahico_report()`/`derive_filtered_annotation()` entry points |
| `inst/rmarkdown/templates/` | The two parameterized Rmd report templates (`01_mhc_report`, `02_mhc_upsets`), packaged for `rmarkdown::draft()`/`run_howmahico_report()` |
| `tests/testthat/` | testthat-edition-3 suite (hand-synthesized fixtures — never derived from real instrument data) |
| `man/` | Generated roxygen2 documentation (`.Rd`) |
| `1_documentation/` | Sample annotation CSVs (one per analysis subset) |
| `2_data/` | Raw search-engine output + cached `pep_all` (not tracked — see `.gitignore`) |
| `3_results/` | Generated csv/xlsx result tables (not tracked) |
| `4_figures/` | Optional generated PNG plot exports (not tracked) |
| `0_code/` | Legacy pre-package reference copies (`00_functions.R`, the two Rmds, the render driver) — superseded by `R/`/`inst/`, about to be removed |

> `2_data/`, `3_results/`, `4_figures/`, and the rendered `*.html` reports are
> regenerated by running the pipeline and are excluded from version control —
> see `.gitignore`.

## Requirements

- R (>= 3.5.0) with [RStudio](https://posit.co/download/rstudio-desktop/) (project
  file: `HowMaHiCo.Rproj`)
- Install the package (e.g. `devtools::install_github("DavidGZ1/HowMaHiCo")` or
  `devtools::load_all()` from a clone) — all dependencies are declared in
  `DESCRIPTION` (`Imports`/`Suggests`) and resolved automatically; no manual
  library list or companion-package install required (the one `deltaProtR` function
  HowMaHiCo needs, `get_dirs_index_peaks()`, is vendored into
  `R/vendored-deltaprotr.R`)

## How to run

1. Place raw search-engine output under `2_data/<software>/<condition>/...`
2. Fill in a sample annotation CSV under `1_documentation/` (or auto-generate a
   skeleton with `0_code/00_extract_sample_info_fragpipe.R`)
3. Render a report with `library(HowMaHiCo)` + `run_howmahico_report()`:

   ```r
   library(HowMaHiCo)
   run_howmahico_report(
     template = "01_mhc_report",            # or "02_mhc_upsets"
     params = list(Title = "Report: MHC1p evaluation - dda_all",
                   AnnotationFile = "sample_annotation_dda_all.csv",
                   FolderDocumentation = "1_documentation",
                   Subset = "dda_all",
                   FolderData = "2_data", FolderResults = "3_results", FolderFigures = "4_figures",
                   Software = "fragpipe_dda_combined", ...),
     output_file = "01_report_main__hla1_dda_all.html"
   )
   ```

   `FolderDocumentation`/`FolderData`/`FolderResults`/`FolderFigures` are absolute
   (or render-time-working-directory-relative) paths — the template ships inside an
   installed package and can be rendered from anywhere. One call renders one report;
   loop it for the `{dda,dia} × {all,jy,plasma}` 6-subset batch pattern (see the
   `\dontrun{}` example on `run_howmahico_report`/`derive_filtered_annotation`).

Reports are written to `output_file` (HTML), and result tables/figures are written
under `<FolderResults>/<subset>/` and `<FolderFigures>/<subset>/`.
