# HowMaHiCo: LC-Immunopeptidomics QC Reporting Workflow

Ingests LC-MS search-engine output (FragPipe, DIA-NN, PEAKS) for
LC-immunopeptidomics (MHC/HLA peptide) experiments, normalizes it into
one unified long-format peptide table, and renders self-contained
interactive HTML QC reports plus csv/xlsx/png result exports via a
parameterized RMarkdown template.
